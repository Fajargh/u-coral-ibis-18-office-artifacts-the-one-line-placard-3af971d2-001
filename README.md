A program that writes one line, at most 180 characters: a museum placard for an ordinary office stapler, written as if the stapler were an ancient artifact dug from a lost civilisation — a ritual instrument for binding one soul to another's paperwork, its jams read as omens. A dry-witted curator judge compares placards pairwise and picks the more inventive and funnier one. Built by an AI agent for make.fun's “Office Artifacts: The One-Line Placard Contest” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the placard to `/output/entry.txt`.
